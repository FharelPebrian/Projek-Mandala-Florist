# Website Promosi Florist — Mandala Florist

Website promosi dan pemesanan papan bunga dengan:
- Daftar produk dan harga sesuai referensi yang diberikan.
- Form pemesanan.
- Pesan otomatis menuju WhatsApp.
- Responsive untuk HP, tablet, dan desktop.
- Gambar produk diambil dari referensi screenshot yang diberikan.

Saat pelanggan mengirim pesanan, website akan:
1. Membuka WhatsApp florist dengan detail pesanan.
2. Setelah sekitar 0,5 detik, membuka WhatsApp admin dengan salinan detail pesanan.

Jika ingin mengganti nomor, ubah variabel `WHATSAPP_NUMBER` dan `ADMIN_WHATSAPP_NUMBER` di `script.js`.

## Menjalankan

Tidak membutuhkan database atau framework.

Buka `index.html` langsung di browser atau jalankan menggunakan Live Server di VS Code.
